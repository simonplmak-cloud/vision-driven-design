# VDD Community Call Schedule

> Impact Chain: V-001 → S-002 → T-003 → A-012

## Format

- **Frequency**: Monthly
- **Duration**: 45 minutes
- **Platform**: GitHub Discussions (async) + optional live stream
- **Time**: Rotating between APAC, EMEA, and AMER-friendly slots

## Monthly Agenda

| Segment | Time | Description |
|---------|------|-------------|
| VDD updates | 5 min | What's new in the latest release |
| Community showcase | 10 min | A VDD adopter presents their project |
| Deep dive | 15 min | Walkthrough of a specific VDD feature or pattern |
| Q&A / Office hours | 15 min | Open discussion, troubleshooting, roadmap input |
