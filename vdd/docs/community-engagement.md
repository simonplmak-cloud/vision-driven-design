# VDD GitHub Community Engagement Plan

> Impact Chain: V-001 → S-002 → T-003 → A-018

## Response SLA

| Channel | Response Time | Goal |
|---------|--------------|------|
| Issues (bug) | Within 24 hours | Triage + acknowledge |
| Issues (feature) | Within 48 hours | Discuss + label |
| Discussions | Within 24 hours | Engage + answer |
| PRs (community) | Within 72 hours | Review + merge or provide feedback |

## Good First Issues

Label `good-first-issue` on tasks that:
- Are S-size (under 1 hour)
- Don't require deep VDD methodology knowledge
- Have clear acceptance criteria

Example good first issues:
- Fix typos in reference docs
- Add a new domain-primer section
- Translate a doc page
- Add a missing cross-reference in INDEX.md

## Contributor Recognition

- Every merged PR author gets added to a CONTRIBUTORS section in README.md
- First-contribution PRs get a personal "thank you" comment
- Top contributors featured in monthly community update

## Moderation

- Be welcoming to newcomers
- Assume good intent
- No "RTFM" responses — link to the specific doc section
- Flag spam/abuse for removal
